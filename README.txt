A LITTLE WORLD FOR SAYANGGG ♡

Isi folder:
- index.html: struktur halaman
- style.css: desain, animasi, responsif HP
- script.js: kupu-kupu neon, keypad PIN, navigasi, permainan, hadiah, dan musik dreamy
- assets/sayang.jpg: satu foto yang diberikan

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder tio_little_world.
3. Buka index.html di browser modern.

PIN: 150926

Catatan:
- Musik dibuat secara sintetis menggunakan Web Audio API, jadi tidak membutuhkan file lagu eksternal.
- Browser hanya mengizinkan audio setelah ada interaksi pengguna. Musik mulai setelah tombol masuk ke dunia kita ditekan.
- Tombol musik bisa ditekan untuk ON/OFF. Klik kanan (desktop) atau tekan agak lama (HP yang mendukung) untuk menaikkan volume.
- Google Fonts memerlukan koneksi internet; bila offline, font cadangan akan digunakan.
- PIN ini adalah gerbang sederhana di sisi browser, bukan pengamanan data yang kuat.
